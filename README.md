#DigiTools

DigiTools is a modern and responsive digital product marketplace website where users can explore premium digital tools, view product details, and add their favorite tools to the cart.  
The project is designed with a clean UI and smooth user experience to make browsing digital products simple and engaging.

##Project Description

This project showcases a premium digital tools platform built with React.  
Users can browse different digital products, switch between product and cart sections, and manage selected tools easily.  
The interface is fully responsive and designed to look modern across desktop and mobile devices.

##Technologies Used

React.js
Tailwind CSS
JavaScript (ES6)
HTML5
CSS3

#Features

##Product Showcase
Users can browse a collection of premium digital tools with pricing, features, and special tags like **Popular**, **New**, and **Best Seller**.

##Add to Cart Functionality
Users can add products to the cart, and the cart count updates dynamically in the navbar.

##Fully Responsive Design
The website is responsive and optimized for mobile, tablet, and desktop screens.
